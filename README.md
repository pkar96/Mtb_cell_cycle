This repo contains code for elucidating _M. tuberculosis_ (Mtb) cell cycle.

Data for 347 individual cell cycle events such as birth, division and initiation of DNA replication can be found in christin_cellcycletiming_all_new.xlsx.
-analyse_cycle_data.m can be used to generate correlation and conditional correlation between two cell cycle variables (Figures 2 and 3).

simulation folder contains folders to generate Figure 4
- Running the call_fmin.m in "calc params" will find the parameters for each of the models (CH model, parallel adder, and concurrent processes) by maximizing the log-likelihood.
- Figure 4 can be generated by running call.m in "gen corr plots".
- Running call_multi.m in "calc final stats" gives AIC values for each model.
